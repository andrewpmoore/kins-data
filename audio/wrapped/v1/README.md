# Kins Wrapped audio

The user supplied these recordings for Kins Wrapped. Files were transcoded to AAC in M4A containers for iOS playback; SHA-256 and byte counts in `catalog.json` refer to the published AAC files.

`age` is the completed age at the start of the Wrapped year: `age: 0` plays for Year 1, `age: 16` for Year 17, and `age: 17` for Year 18. The `theme` recording is the fallback for every other year and for an unavailable named-year file.

The `user-supplied` label records provenance; it is not a Creative Commons licence claim.
